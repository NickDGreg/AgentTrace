# crawl_test

Internal notes for maintainers. This file is not part of site UI.

## Purpose
- Crawl-friendly variant of `site_one` for discovery/extraction evaluation.

## Access model
- Public pages include `/`, `/index`, `/account`, and `/account/deposit-panel`.
- Login/register routes still exist, but core extraction pages are intentionally reachable without login.
- User selection for account/deposit views:
  - Session user if logged in.
  - Else seed user (`user1@example.com`).
  - Else first DB user.

## Seed user
- Email: `user1@example.com`
- Password: `pass1`
- Seed profile name: `Golden Pilot`

## Address model
- Same deterministic model as `site_one`.
- Generated by `_generate_address(user_id, asset)` from:
  - `"{user_id}:{asset}:goldentradr"`
- Same user -> stable addresses; different users -> different addresses.

## Key routes for extraction tasks
- `GET /account`
- `GET /account/deposit-panel` (wallet addresses + QR data URIs)
- Optional auth path: `GET/POST /login`

## Runtime notes
- Compose port: `18084`.
