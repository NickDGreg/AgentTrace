# Core Beliefs

1. Benchmark before framework.
AgentTrace defines environments and scoring contracts, not an agent implementation.

2. Determinism is a feature.
Every benchmark task should produce stable outcomes across repeated runs.

3. Contracts beat conventions.
Task schema, runner behavior, and output payloads must be enforced mechanically.

4. Legibility is required for autonomous agents.
Code and docs should make it obvious where to change behavior and how to verify it.

5. Complexity must earn its place.
Only add site or harness complexity that increases evaluation signal.
